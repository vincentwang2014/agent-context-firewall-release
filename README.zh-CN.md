# Agent Context Firewall（浏览器扩展，开发测试版）

[English](README.md)

在你把消息发给 AI 之前，先在你自己的电脑上检查一遍：密钥、私钥这类内容直接拦下；身份证号、银行卡号这类个人信息，先问你再发。

> **这是开发测试版。** 用来收集反馈，不适合当作唯一的保护手段。

## 它做什么

支持的网站：**claude.ai**、**ChatGPT**（chatgpt.com）、**DeepSeek**（chat.deepseek.com，v0.1.6-dev 起）、**Gemini**（gemini.google.com，v0.1.7-dev 起）。

你按下发送时，扩展先检查这条消息，再决定：

| 检测到 | 处理 |
|---|---|
| 私钥、API 令牌、AWS 访问密钥 | **直接拦截**，不能放行，只能修改内容后再发 |
| 信用卡号、美国银行路由号、美国社会安全号（SSN） | **先问你**，确认后只放行这一次 |
| 上传的文本文件 | 同样检查 |
| 无法检查内容的文件（图片、PDF 等） | 照常上传，不弹卡片；“最近的记录”里记为“未经检查已上传” |
| 扩展自身出错，或看不懂网站发出的内容 | 照常发送，**不经检查**；盾牌变黄，“最近的记录”里有记录 |

原则：只有真正发现敏感内容时，扩展才拦下或先问你。扩展自己做不到的时候，消息照常发出，就像没装扩展一样；扩展会如实说明，而不是打断你。如果你希望“查不了的都先拦住”，可以在设置里选 **严格** 使用风格：查不了的文件先问你，防护不工作时消息不发送。

扩展只读你发出的内容：你输入的消息和你上传的文件，而且只在网站自己的发送和上传地址上读。网站的其他请求（统计、设置、头像等）一概不碰。

工具栏上的盾牌：**绿色** = 防护已开启；**黄色** = 防护暂时没有工作，消息会不经检查直接发送（只有某个标签页是黄色：这个页面上有一条消息或一个文件没有按扩展认识的方式发出，扩展无法确认它经过检查；或者这个页面是在安装、更新扩展之前打开的，需要刷新。弹出窗口里会说明是哪一种）；**红色** = 严格风格下的同样情况，消息不会发送；**灰色** = 正在启动。

## 你的数据

- **检查全部在你的电脑上完成。** 这个版本的扩展自己不向任何地方发送数据；它只读取自己安装包里的文件。
- 扩展只在本机保存：最近 10 条记录的**时间、网站、结果和类别**（例如"已拦截（凭证）"；没发现问题的普通发送不记录），以及你选的使用风格。**不保存消息原文。**
- 你确认放行的记录保存在浏览器会话里，关闭浏览器即清除。
- 卸载扩展即删除以上全部数据。

## 安装

需要桌面版 Chrome。Edge、360、QQ 浏览器等 Chromium 内核浏览器一般也可以：在它们的扩展管理页打开“开发者模式”，再“加载已解压的扩展程序”，菜单位置略有不同。

1. 在 [Releases](../../releases) 下载最新的 `acf-browser-….zip`。
2. （可选）核对完整性：zip 的 SHA-256 应与同一 Release 里 `.SHA256SUMS` 文件最后一行一致。
   Windows：`certutil -hashfile acf-browser-….zip SHA256`；macOS / Linux：`shasum -a 256 acf-browser-….zip`
3. 解压。
4. 打开 `chrome://extensions`，打开右上角的 **开发者模式**。
5. 点 **加载已解压的扩展程序**，选择解压出来、里面有 `manifest.json` 的那个文件夹。
6. 刷新已经打开的 claude.ai / ChatGPT 页面。
7. 点工具栏的拼图图标，把盾牌固定到工具栏，确认它是绿色。

**卸载：** 在 `chrome://extensions` 里点 **移除**。

## 已知限制

- **开发版签名：** 规则包用公开的开发密钥签名，只能发现文件损坏，不能防止有意篡改。正式版会换成发布者密钥。
- **可能误报：** 例如某些 9 位数字可能被当成 SSN。
- **只覆盖上面两个网站**，而且只检查从网页发出的消息；网站改版可能导致某些发送方式暂时检查不到，扩展发现时会在弹出窗口里对这个标签页说明。
- **网站改了格式或扩展不工作期间，消息会不经检查发出**（严格风格除外）。你会在盾牌和弹出窗口里看到，页面上不会弹提示。
- 使用风格：真正发现敏感内容时，三种风格都同样拦截或先问你；只有“严格”会拦下扩展无法检查的内容。
- 界面语言跟随 Chrome 的显示语言（中文或英文）。
- **不监控其他扩展。** 本扩展检查的是这两个网站发给 AI 服务的内容。如果别的浏览器扩展读取页面内容，再从它自己的后台发出去，本扩展看不到，也拦不住——Chrome 不允许一个扩展查看另一个扩展的网络请求。这要靠杀毒或反恶意软件，以及只安装你信任的扩展（在公司里，通常由统一的扩展白名单来管）。
